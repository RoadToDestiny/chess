# Backend 2 — Подготовка и проверка шахматных данных

## Этап 1. Подготовка окружения

Создано виртуальное окружение Python. Установлены и проверены библиотеки:
- python-chess
- pandas
- numpy

Проверена возможность чтения PGN-файлов и получения итоговой позиции FEN.

## Этап 2. Проверка метаданных PGN

На тестовых PGN-записях проверено чтение следующих полей:
- WhiteElo — рейтинг белых;
- BlackElo — рейтинг чёрных;
- TimeControl — контроль времени;
- Result — результат партии;
- White и Black — имена игроков.

Проверено обнаружение отсутствующих значений средствами pandas. Во второй тестовой партии отсутствовали рейтинги обоих игроков и контроль времени.

Примечание: проверка выполнена на двух искусственных партиях и не характеризует полноту реального набора данных.

## Этап 3. Работа с шахматными позициями

С помощью python-chess проверено:
- получение FEN начальной и последующих позиций;
- подсчёт полуходов;
- определение номера хода;
- определение стороны, которой предстоит ходить.

## Этап 4. Минимальный рабочий пример

Реализовано:
- чтение PGN-партии;
- получение шахматной позиции и FEN;
- определение игрока и номера полухода;
- извлечение рейтингов и контроля времени;
- формирование строки данных с идентификаторами партии и позиции;
- сохранение целевого хода в формате UCI.

Оценка Stockfish в текущем примере тестовая. Интеграция с реальным движком выполняется совместно с Backend 1.

## Этап 5. Проверка разметки

Реализованы проверки:
- наличия обязательных полей;
- бинарного значения `error`;
- связи `position_id` с партией и полуходом;
- соответствия цвета игрока стороне хода;
- соответствия FEN номеру полухода;
- легальности целевого хода.

Расчёт потери оценки Stockfish и присвоение меток выполняются Backend 1.

## Этап 6. Извлечение признаков

Реализовано извлечение следующих признаков:
- оценка Stockfish;
- материальный баланс;
- количество фигур и пешек;
- количество легальных шахов и взятий;
- количество и материальная ценность атакованных фигур;
- номер хода и стадия партии;
- изменение оценки относительно предыдущей позиции;
- рейтинги игроков и разница рейтингов;
- параметры контроля времени;
- оставшееся время игрока, если доступно.

Все признаки рассчитываются по позиции до целевого хода.

Отсутствующие значения представлены как `None`. Идентификаторы и целевая переменная не включаются в набор признаков модели.

## Установка

```bash
python -m venv .venv
```

Активация Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

## Запуск минимального примера

```bash

```

```bash
python -m pytest -v
```

## Ограничения и дальнейшая интеграция

- Формат оценок Stockfish необходимо согласовать с Backend 1.
- Тестовая оценка в минимальном примере не является результатом реального анализа Stockfish.
- Формат сложных временных контролей требует дополнительной обработки.
- Интеграция с моделью XGBoost и проверка итогового датасета выполняются совместно с Backend 3.
